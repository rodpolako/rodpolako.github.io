# Changes in this version:

## New features ##
* Crunch mode - Added a feature to automatically retry any failed puzzles.  With this setting turned on, the testing will continue until all the puzzles have been completed correctly.  Any failed puzzles will be retested until correct.

## Bug fixes ##
* Fixed a bug where the locally cached copy of lichess studies would remain if the Lichess UserID changed.
* Fixed a bug where the list of studies don't always retain the corect sort.
* Fixed a bug where annotations and drawings were not present in the retried lines.
* Fixed minor cosmetic error with the lcoation of the sort functions in the Lichess study listing.

## Maintenance ##
* No other maintenance items with this release.
